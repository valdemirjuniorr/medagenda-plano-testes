## Sobre o sistema testado

O MedAgenda é um software que organiza a rotina de uma clínica com 3 especialidades. O sistema usa Node.js, React, MongoDB e Docker.

O sistema é testado como foi entregue: o código da aplicação não é alterado. Os testes ficam em pasta própria neste repositório.

## Conteúdo do repositório

Este repositório reunirá o plano de testes, os casos de teste, a suíte automatizada, os relatórios de execução e defeitos e o parecer de validação.

- `tests/`: testes automatizados (API, interface, desempenho e acessibilidade)

A estrutura será atualizada conforme o projeto avança.
